# Nova Surge

A browser action game with automatic firing, upgrades, and a surge ability.

[Play the public demo](https://sh-binx.github.io/nova-surge-demo/)

## Controls

- Drag or use the left and right arrow keys to move.
- Firing is automatic.
- Press Space to activate Surge when its meter is full.
- Open Ships & Upgrades from the menu to see the available upgrades.

## This repository

GitHub Pages serves the static demo from this repository. `index.html` is the entry point; the `slice/` directory contains supporting files.

The live page currently labels this build **Nova Surge 2.0**.
