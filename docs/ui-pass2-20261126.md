# 2차 개선 설계 — 전투 화면 품질·타격감 (2026-11-26)

근거: 2026-11-26 플레이 점검 문제 1(전투 화면이 시작 화면 기대에 못 미침)·7(서지 연출 약함)과 1차 독립 검토의 잔여 지적. 오너 「2차 끝나고 한 번에」(앱인토스 재출시는 2차 뒤).
범위는 보이는 것과 반응뿐이다. 적 체력·속도·출현 순서, 판정 반경(FOE.r), 점수·자원 계산은 바꾸지 않는다(난이도·구성은 3차).

## 호출 흐름

- `kill()` → `burst()`·`pop()`×2·`ring()` → 프레임 루프의 debris/pops/rings 갱신 → 풀 반납. `reset()` 이 pops 도 비운다.
- `fireSurge()` → `FLASH.w`·`S.surgeFx` 설정 → `drawFX()` 가 방사선·가장자리 테를 그림(기체 화면 좌표는 `toScr`).
- 풀 상한: pops 28, rings 20(기존 8), debris 85(기존) — 90마리 동시 상황에서도 그리기 호출이 늘지 않게 상한 유지.
