# Nova Surge 전투 흐름 개선

기존 3D 생존 슈팅·그레이즈/SURGE·40웨이브와 8보스는 유지한다.
보스전 중 진행 시계를 멈춰 순서 누락을 방지하고 증원은 35%로 낮춘다.
보스 처치 뒤 잔탄 제거·4.2초 보급 여유와 짧은 무적을 제공한다.
성장 선택은 미완성 주력 무기와 보조 선택을 보장하고 나머지를 무작위로 구성한다.
경험치 요구량 지수 폭증을 180 상한으로 제한해 후반에도 성장 선택을 유지한다.
20웨이브 이후 적 체력 증가를 8%에서 3.5%로 완화한다.
에픽 카드가 업그레이드 상한을 초과하는 문제와 재시작 SURGE 횟수 잔존을 수정한다.

## 검수 결과
- 실제 WebGL 브라우저에서 개발용 자동 조종·가속 실행, 정상 전투와 성장 카드 선택만으로 834초 / WAVE 40 / 보스 8회 처치 / sectorCleared=true 확인. 강제 체력·무기 지급·보스 처치 없이 진행한 경로다.
- 별도 회귀 시험은 보스 등장 직전 시각 주입 → 보스가 살아 있는 2초 동안 웨이브 시계 고정 → 강제 처치 뒤 진행 재개를 확인했다. 이는 완주 증거와 구분한다.
- SURGE 사용 후 재시작 횟수 0 확인.
- 844×390 성장 카드 이름은 밝은색(rgb234,240,255), 카드 하단308px로 화면 안에 표시됨.
- 일반 속도 실제 브라우저 화면 녹화 30.2초(자동 조종, 무음). 화면 캡처 표본 약7fps이며 인코딩30fps는 실제 게임 프레임 측정치가 아니다.
- 스크립트 5개 파싱·git diff --check 통과. 독립 정적 검토 지적 0(카드 기본색 회귀 수정 후).
- DEV 검수 점수는 서버에 제출하지 않도록 차단했다.
- 실물 iPhone 및 초행 사람 플레이의 재미·난도 평가는 이 검수에 포함하지 않는다. 한 자동 조종 빌드 완주는 모든 빌드의 난도 보증이 아니다.
- 롤백 기준 c4b4580 (PR1). 장르·과금·앱인토스 배포는 변경하지 않는다.
