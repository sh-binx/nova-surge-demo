# Nova Surge 웹판 개선 · 2026-11-17

기존 3D 오토파이어·그레이즈/SURGE·기체·성장 규칙 유지.
새 홍보 키아트는 이미지 생성 도구로 제작했으며 실제 게임 스크린샷이 아니다.
시작 화면, HUD, 격납고의 가로 모바일 배치·터치 크기·대비 개선.
조종 포인터를 소유한 손가락만 이동에 반영, SURGE와 동시 입력 가능.
창 이탈 시 키 상태 초기화·일시정지. 키보드 버튼 접근 추가.

검증: JS 파싱 전체 통과. 실제 Chromium 1440×900, 가로 844×390 시작/격납고/출격/정지·재개 확인.
CDP 두 손가락 입력 중 이동 유지 및 SURGE 횟수 증가, Enter SURGE, blur 정지 확인. 콘솔 error 0.
실물 아이폰 및 장시간 완주 검증으로 확대 해석하지 않는다. 앱인토스 배포는 이번 웹판 작업에 포함하지 않음.
독립 검토에서 발견한 모바일 메뉴 숨김·SURGE 스코프·보스바 겹침은 수정 후 재확인.
