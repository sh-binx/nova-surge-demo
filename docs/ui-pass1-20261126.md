## 구조

- HUD 마크업: `#sideL` 에서 `.ptitle` 삭제, 체력 줄에 `<span id="hpn">` 추가. `#pauseBtn` 은 위치만 CSS 로 옮긴다(아이디 유지 — 기존 시험과 토스 뒤로가기 처리 호환).
- `setUI()`: `hpn` 숫자, `#sideL.low`(체력 30% 이하) 토글.
- `leak()`: `S.leakToastN` 으로 설명 띠 2회 제한, `hpPulse()` 호출(체력 줄에 `.hit` 클래스 320ms).
- `renderLoadout()`: 비었을 때 `.loempty` 대신 빈 문자열, 라벨은 CSS `:has()` 대신 `#sideL.noload` 클래스로 숨김(WebKit 구판 대비).
- 광고 제안: `grabCrate()` 에서 `S.t>=60 && S.t-S.lastOfferT>=75` 일 때만 `crateBonusPending`.
- 결과: `die()` 가 `S.deathBy`('leak'|'hit')와 `newBest` 를 넘겨 `overStats` 에 표시, `#hgBtn2` 클릭 → `hgOpen()`.
- 나가기 확인: `quitBtn` 첫 탭은 문구만 바꾸고 3초 뒤 원복, 두 번째 탭에 `quitToMenu()`.
