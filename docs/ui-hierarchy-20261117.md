# UI 위계 재검토

이전 개선은 화면 대응과 입력에 집중했고 캔버스 웨이브 알림·보상·카드 아이콘의 발광/테두리가 남았다. 테두리 유무만으로 품질을 판단하지 않고, 상태 정보와 행동 버튼의 강조 수준을 구분한다.

- 웨이브 캔버스 알림: 발광 외곽선 → 짙은 면·작은 측면 색 표시, 화면 폭에 맞춘 제목 크기.
- HUD: 보유 재화·보조 장비 박스 제거, 숫자와 행 정렬로 구분. 선택 무기는 밝은 채움.
- SURGE: 충전 진행 링은 의미가 있으므로 유지. 중첩 테두리·맥동 제거, 준비 완료는 면 색상 변화.
- 성장 카드: 외곽선·발광·아이콘 박스 제거. 희귀도 배지는 별도 위치, 제목·레벨 기준선 동일. 일반/에픽 면 색을 구분.
- 보상과 격납고: 채움 버튼·동일 서체, 과한 장식 기호 제거. 격납고 뒤 전투 기체 비침 제거.

검수: ego 실제 Chromium 1440×900·844×390. 모바일 카드 제목 y=210.25 동일, 카드 bottom317.25 <390, 격납고 Back bottom382 <390. Enter 성장 선택 → PULSE Lv2, 정지/재개, 보급 선택/계속 비행 state=play, 수집된 JS error0.
독립 디자인/코드 검토: Epic의 'Double upgrade'가 상한 직전에 과장되는 지적을 받아 'Epic'으로 수정. 사람 대상 사용성 테스트를 수행했다거나 모든 기기에서 최적임을 뜻하지 않는다.
